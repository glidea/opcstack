# 支付

在 **后台 > 系统设置 > 支付** 连接支付平台，在 **后台 > 支付商品** 将远端商品关联到用户权益。支付配置保存在 D1，保存后对新请求立即生效。

先在支付平台后台创建商品，再到支付商品工作区选择已连接平台和远端商品。系统自动读取名称、价格、币种、计费类型、环境和远端 ID，管理员只填写本地积分或订阅权益。

每个启用的平台都需要 API Key 和 Webhook 签名密钥。把页面展示的 Webhook URL 配置到平台后台。系统根据 API Key 自动识别测试或生产环境；切换凭据后，另一环境关联的商品不会进入当前结账目录。

商品编辑使用乐观版本控制。过期版本更新或删除仍被有效订阅引用的商品会被拒绝，不会覆盖当前配置。

密钥保存后不再显示明文。替换 Webhook 密钥后，下一个请求立即使用新密钥校验。

Provider 配置和商品独立保存。商品操作成功后只更新当前页面中的目标商品，删除前必须确认。其他浏览器已经修改同一商品时，需要刷新当前数据后重新编辑。
